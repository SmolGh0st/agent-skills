This skill's full toolkit (scripts, reference docs, sub-agents) lives in its
source repo and is tightly coupled to that repo's own tooling. Rather than
mirror ~140 files that likely won't function correctly relocated, install it
directly from the source:

  npx skills add https://github.com/pbakaus/impeccable --skill impeccable

This includes polish, quieter, delight, and critique as sub-skills.
